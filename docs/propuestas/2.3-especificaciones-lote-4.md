## CU-016 · Gestionar servicios y precios

| Campo | Descripción |
|---|---|
| Actor principal | Administrador |
| Requisitos relacionados | RF-012, RN-001, RN-010, RN-011 |
| Objetivo | Mantener el catálogo de servicios del negocio. |
| Precondiciones | El administrador ha iniciado sesión. |
| Disparador | Abre "Servicios". |
| Datos de entrada | Nombre, descripción, duración, precio y estado (activo o inactivo). |
| Flujo principal | 1. El sistema lista todos los servicios. 2. El administrador crea uno nuevo o edita uno existente. 3. El sistema valida que el nombre no se repita, que el precio no sea negativo y que la duración sea múltiplo del intervalo (RN-011). 4. Guarda los cambios. |
| Flujo alternativo 1 | Desactivar un servicio: deja de mostrarse y de poder reservarse; las citas ya confirmadas se mantienen. Los servicios no se borran para conservar el historial. |
| Flujo alternativo 2 | Cambio de precio o duración: solo afecta a las reservas nuevas, no a las ya confirmadas. |
| Flujo alternativo 3 | Datos no válidos: se indica el error. |
| Postcondición | El catálogo queda actualizado. |

## CU-017 · Gestionar empleados

| Campo | Descripción |
|---|---|
| Actor principal | Administrador |
| Requisitos relacionados | RF-013, RN-002, RN-005, RNF-001 |
| Objetivo | Dar de alta, modificar o desactivar empleados y asignarles servicios. |
| Precondiciones | El administrador ha iniciado sesión. |
| Disparador | Abre "Empleados". |
| Datos de entrada | Nombre, apellidos, correo, teléfono y servicios que realiza. |
| Flujo principal | 1. El sistema lista los empleados. 2. El administrador da de alta uno nuevo con sus datos. 3. El sistema comprueba que el correo no esté en uso. 4. Crea la cuenta con rol Empleado y una contraseña temporal, que el administrador entrega en persona (RN-005). 5. El administrador le asigna servicios. 6. El empleado hereda el horario general, ajustable en CU-018. |
| Flujo alternativo 1 | Correo ya en uso: se informa y no se crea la cuenta. |
| Flujo alternativo 2 | Desactivar un empleado con citas futuras: el sistema las muestra y obliga a cancelarlas o reasignarlas antes de completar la desactivación. |
| Flujo alternativo 3 | Quitar un servicio con citas futuras de ese servicio: se avisa; las citas se mantienen. |
| Postcondición | El empleado queda registrado (o actualizado) con sus servicios asignados. |

## CU-018 · Configurar horarios

| Campo | Descripción |
|---|---|
| Actor principal | Administrador |
| Requisitos relacionados | RF-014, RN-002 |
| Objetivo | Definir cuándo se atiende y cuándo trabaja cada empleado. |
| Precondiciones | El administrador ha iniciado sesión. |
| Disparador | Abre "Horarios". |
| Datos de entrada | Por día de la semana: tramos de apertura (por ejemplo, 09:00-14:00 y 16:00-20:00). Por empleado: ajustes sobre el horario general. Días de cierre (festivos, vacaciones). |
| Flujo principal | 1. El administrador define el horario general. 2. Opcionalmente ajusta el horario de un empleado. 3. Opcionalmente añade días de cierre del negocio o de un empleado. 4. El sistema valida que los tramos no se solapen y que el inicio sea anterior al fin. 5. Guarda y aplica el horario a las nuevas consultas de disponibilidad. |
| Flujo alternativo 1 | Hay citas confirmadas que quedan fuera del nuevo horario o en un día de cierre: el sistema las lista para que el administrador decida cancelarlas o mantenerlas. |
| Postcondición | La disponibilidad (CU-007) se calcula con el nuevo horario. |

## CU-019 · Consultar y gestionar reservas

| Campo | Descripción |
|---|---|
| Actor principal | Administrador |
| Requisitos relacionados | RF-015, RN-004, RN-008, RNF-003 |
| Objetivo | Supervisar todas las reservas del negocio y actuar sobre ellas. |
| Precondiciones | El administrador ha iniciado sesión. |
| Disparador | Abre "Reservas". |
| Datos de entrada | Filtros: fechas, profesional, estado y cliente. |
| Flujo principal | 1. El sistema muestra todas las reservas con filtros. 2. El administrador abre una reserva para ver su detalle. 3. Puede cambiar su estado con las mismas transiciones de CU-015, o cancelarla en cualquier momento indicando un motivo (RN-004). |
| Flujo alternativo 1 | Crear una reserva en nombre de un cliente registrado (por ejemplo, si llama por teléfono): sigue CU-008 eligiendo antes al cliente; la comprobación de disponibilidad es la misma (RNF-003). |
| Flujo alternativo 2 | No hay reservas con esos filtros: se informa. |
| Postcondición | Las reservas quedan actualizadas y cada cambio queda registrado con quién lo hizo. |
