## CU-005 · Consultar servicios y precios

| Campo | Descripción |
|---|---|
| Actor principal | Visitante o Cliente |
| Requisitos relacionados | RF-003, RN-001 |
| Objetivo | Conocer los servicios que ofrece el negocio. |
| Precondiciones | Existe al menos un servicio activo. |
| Disparador | Abre la sección "Servicios". |
| Flujo principal | 1. El sistema muestra los servicios activos. 2. Para cada uno muestra nombre, descripción, duración y precio. 3. El actor puede seleccionar un servicio para ver qué profesionales lo realizan (CU-006) o reservarlo (CU-008). |
| Flujo alternativo 1 | No hay servicios activos: se muestra un mensaje informativo. |
| Postcondición | Ninguna; la consulta no modifica datos. |

## CU-006 · Consultar profesionales

| Campo | Descripción |
|---|---|
| Actor principal | Visitante o Cliente |
| Requisitos relacionados | RF-004, RF-013 |
| Objetivo | Conocer a los profesionales y los servicios que realiza cada uno. |
| Precondiciones | Existe al menos un profesional activo. |
| Disparador | Abre la sección "Profesionales" o elige un servicio. |
| Flujo principal | 1. El sistema muestra los profesionales activos (filtrados por servicio si se eligió uno). 2. Para cada uno muestra nombre y servicios que realiza. |
| Flujo alternativo 1 | Ningún profesional realiza el servicio elegido: se informa. |
| Postcondición | Ninguna. |

## CU-007 · Consultar horarios disponibles

| Campo | Descripción |
|---|---|
| Actor principal | Visitante o Cliente |
| Requisitos relacionados | RF-005, RN-001, RN-002, RN-009, RN-010 |
| Objetivo | Ver en qué horas se puede reservar un servicio con un profesional. |
| Precondiciones | El servicio y el profesional están activos y el profesional realiza ese servicio. |
| Disparador | Elige servicio, profesional y fecha. |
| Datos de entrada | Servicio, profesional y fecha. |
| Flujo principal | 1. El sistema toma el horario laboral del profesional para esa fecha (RN-002). 2. Descarta los tramos ocupados por citas Confirmadas. 3. Genera horas de inicio cada 30 minutos (RN-010) en las que la duración del servicio (RN-001) cabe completa. 4. Descarta las horas ya pasadas. 5. Muestra las horas disponibles. |
| Flujo alternativo 1 | La fecha supera los 60 días de antelación (RN-009) o es pasada: no se permite elegirla. |
| Flujo alternativo 2 | No hay huecos ese día: se informa y se sugiere el siguiente día con disponibilidad. |
| Postcondición | Ninguna; las horas mostradas no quedan reservadas. |

## CU-008 · Reservar cita

| Campo | Descripción |
|---|---|
| Actor principal | Cliente |
| Requisitos relacionados | RF-006, RF-007, RN-003, RNF-003 |
| Objetivo | Reservar un servicio con un profesional en una fecha y hora disponibles. |
| Precondiciones | El cliente ha iniciado sesión. |
| Disparador | Selecciona una hora disponible y pulsa "Reservar". |
| Datos de entrada | Servicio, profesional, fecha y hora (obtenidos en CU-007). |
| Flujo principal | 1. El cliente elige servicio, profesional, fecha y hora (CU-007). 2. **Punto de extensión: ¿para quién es la cita?** 3. El sistema muestra un resumen (servicio, profesional, fecha, hora, duración y precio). 4. El cliente confirma. 5. El sistema vuelve a comprobar la disponibilidad en el momento de guardar (RF-007). 6. Registra la cita con estado Confirmada (RN-003). 7. Muestra la confirmación. |
| Flujo alternativo 1 | El visitante no ha iniciado sesión: se le pide iniciar sesión o registrarse y después se recupera su selección. |
| Flujo alternativo 2 | Otro cliente reservó ese hueco entre los pasos 1 y 5: no se guarda la cita, se informa y se muestran otras horas (RNF-003). |
| Postcondición | La cita queda registrada como Confirmada y el hueco deja de estar disponible. |

## CU-009 · Reservar cita para un menor a cargo

| Campo | Descripción |
|---|---|
| Actor principal | Cliente |
| Requisitos relacionados | RF-017, RN-006, RN-007, RNF-007 |
| Relación | «extend» de CU-008 en el punto de extensión "¿para quién es la cita?". |
| Objetivo | Reservar una cita cuyo beneficiario es un menor de 14 años a cargo del cliente. |
| Precondiciones | El cliente está en CU-008. |
| Disparador | En el punto de extensión elige "Para un menor a mi cargo". |
| Datos de entrada | Nombre, apellidos y fecha de nacimiento del menor (solo los datos imprescindibles). |
| Flujo principal | 1. El sistema muestra los menores ya registrados por el cliente o permite añadir uno. 2. El cliente selecciona o añade al menor. 3. El sistema comprueba que tiene menos de 14 años. 4. Registra al cliente como responsable y al menor como beneficiario. 5. Continúa en el paso 3 de CU-008. |
| Flujo alternativo 1 | El beneficiario tiene 14 años o más: se informa de que debe crear su propia cuenta. |
| Postcondición | La cita tiene como beneficiario al menor y como responsable al cliente. |

## CU-010 · Consultar próximas citas

| Campo | Descripción |
|---|---|
| Actor principal | Cliente |
| Requisitos relacionados | RF-008 |
| Objetivo | Ver las citas futuras propias y de sus menores a cargo. |
| Precondiciones | El cliente ha iniciado sesión. |
| Disparador | Abre "Mis citas". |
| Flujo principal | 1. El sistema muestra las citas futuras ordenadas por fecha. 2. Para cada una indica fecha, hora, servicio, profesional, beneficiario y estado. 3. El cliente puede abrir el detalle (CU-011). |
| Flujo alternativo 1 | No tiene citas futuras: se informa y se ofrece reservar. |
| Postcondición | Ninguna. |

## CU-011 · Consultar detalle de una cita

| Campo | Descripción |
|---|---|
| Actor principal | Cliente |
| Requisitos relacionados | RF-008, RN-004 |
| Objetivo | Ver toda la información de una cita. |
| Precondiciones | La cita pertenece al cliente (o a un menor a su cargo). |
| Disparador | Selecciona una cita en "Mis citas". |
| Flujo principal | 1. El sistema muestra servicio, profesional, fecha, hora, duración, precio, beneficiario y estado. 2. Si la cita está Confirmada y faltan 24 horas o más, muestra la opción "Cancelar" (CU-012). |
| Flujo alternativo 1 | La cita no pertenece al cliente: acceso denegado (RNF-002). |
| Postcondición | Ninguna. |

## CU-012 · Cancelar cita

| Campo | Descripción |
|---|---|
| Actor principal | Cliente |
| Requisitos relacionados | RF-009, RN-004, RN-008 |
| Objetivo | Anular una cita que ya no necesita. |
| Precondiciones | La cita está Confirmada y pertenece al cliente. |
| Disparador | Pulsa "Cancelar" en el detalle de la cita. |
| Flujo principal | 1. El sistema pide confirmación. 2. El cliente confirma. 3. El sistema comprueba que faltan 24 horas o más. 4. Cambia el estado a Cancelada. 5. El hueco vuelve a estar disponible. 6. Confirma la cancelación. |
| Flujo alternativo 1 | Faltan menos de 24 horas: no se permite cancelar y se indica que contacte con el negocio (RN-004). |
| Postcondición | La cita queda Cancelada y su horario se libera. |
