## CU-013 · Consultar agenda

| Campo | Descripción |
|---|---|
| Actor principal | Empleado |
| Requisitos relacionados | RF-010, RN-002, RNF-002 |
| Objetivo | Ver su jornada y sus citas en un calendario. |
| Precondiciones | El empleado ha iniciado sesión. |
| Disparador | Abre "Mi agenda". |
| Datos de entrada | Vista (día o semana) y fecha. |
| Flujo principal | 1. El sistema muestra por defecto el día actual. 2. Muestra su horario laboral (RN-002) y, encima, sus citas no canceladas con hora, servicio y estado. 3. El empleado puede cambiar de día o pasar a la vista semanal. 4. Puede abrir una cita para ver su detalle (CU-014). |
| Flujo alternativo 1 | No tiene horario ese día: se indica "día no laborable". |
| Flujo alternativo 2 | Intenta ver la agenda de otro empleado: acceso denegado (RNF-002). |
| Postcondición | Ninguna; la consulta no modifica datos. |

## CU-014 · Consultar citas asignadas

| Campo | Descripción |
|---|---|
| Actor principal | Empleado |
| Requisitos relacionados | RF-010, RNF-002, RNF-007 |
| Objetivo | Revisar en lista las citas que tiene asignadas y su detalle. |
| Precondiciones | El empleado ha iniciado sesión. |
| Disparador | Abre "Mis citas" o selecciona una cita en la agenda. |
| Datos de entrada | Filtros opcionales: rango de fechas y estado. |
| Flujo principal | 1. El sistema muestra sus citas ordenadas por fecha y hora. 2. Permite filtrar por fechas y estado. 3. Al abrir una cita muestra servicio, fecha, hora, duración, estado, nombre y teléfono del cliente y, si existe, el nombre del menor beneficiario. |
| Flujo alternativo 1 | No hay citas con esos filtros: se informa. |
| Postcondición | Ninguna. Solo se muestran los datos del cliente necesarios para atender la cita (minimización, RNF-007). |

## CU-015 · Actualizar estado de una cita

| Campo | Descripción |
|---|---|
| Actor principal | Empleado |
| Requisitos relacionados | RF-011, RN-004, RN-008 |
| Objetivo | Reflejar qué ocurrió con una cita. |
| Precondiciones | La cita está asignada al empleado y su estado es Confirmada. |
| Disparador | En el detalle de la cita elige un nuevo estado. |
| Datos de entrada | Nuevo estado y, si es Cancelada, motivo. |
| Flujo principal | 1. El sistema muestra solo los cambios permitidos. 2. El empleado elige el nuevo estado. 3. El sistema valida la transición. 4. Guarda el estado, la fecha del cambio y quién lo hizo. 5. Si el nuevo estado es Cancelada, el hueco vuelve a estar disponible. |
| Transiciones permitidas | Confirmada → Completada (desde la hora de inicio). Confirmada → No presentado (desde la hora de inicio). Confirmada → Cancelada (en cualquier momento, también con menos de 24 horas, RN-004). Completada, Cancelada y No presentado son estados finales. |
| Flujo alternativo 1 | Intenta marcar Completada o No presentado antes de la hora de inicio: se rechaza. |
| Flujo alternativo 2 | Cancela sin indicar motivo: se pide el motivo. |
| Flujo alternativo 3 | La cita no está asignada a él o ya está en un estado final: no se permite el cambio. |
| Postcondición | La cita queda en el nuevo estado y el cambio queda registrado. |

## CU-021 · Consultar servicios asignados

| Campo | Descripción |
|---|---|
| Actor principal | Empleado |
| Requisitos relacionados | RF-019, RF-013 |
| Objetivo | Saber qué servicios puede realizar y, por tanto, cuáles le pueden reservar. |
| Precondiciones | El empleado ha iniciado sesión. |
| Disparador | Abre "Mis servicios". |
| Flujo principal | 1. El sistema muestra los servicios que el administrador le ha asignado. 2. Para cada uno indica nombre, duración y precio. |
| Flujo alternativo 1 | No tiene servicios asignados: se informa de que no recibirá reservas hasta que el administrador le asigne alguno. |
| Postcondición | Ninguna. |
