## 2. Decisiones que necesito de ti

1. **Cómo se dibuja el diagrama de clases.** Hoy está en draw.io y el `.png`
   se exportó a mano. Aquí no tengo draw.io para exportarlo. Propongo
   **pasarlo a Mermaid** (`Clases.mmd`), como el ER y las secuencias:
   el `.png` se genera con un comando y el diagrama se revisa como texto en
   los PR. El `.drawio` se queda como el original del 2.4. La alternativa es
   que yo edite el `.drawio` y tú exportes el `.png` desde draw.io.
2. **Qué hace la prueba si `openapi.json` está desfasado.** Propongo que
   **falle** (como las matrices de permisos): así nadie olvida regenerarlo. La
   alternativa es que la CI lo regenere y lo guarde como artefacto sin
   fallar. Es más cómodo, pero el archivo del repositorio puede quedarse
   viejo.
3. **Idioma de las descripciones de Swagger.** Propongo **español**, como el
   resto del proyecto (código, errores y documentación). El README en inglés
   del 6c dirá que la API está documentada en español.
